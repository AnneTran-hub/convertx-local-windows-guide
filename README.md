# ConvertX Local Setup Guide for Windows

A beginner-friendly guide for installing and running ConvertX locally on Windows using Docker Desktop.

The goal of this guide is to help non-technical users convert supported files locally instead of uploading private documents to third-party online conversion websites.

## What is ConvertX?

ConvertX is a self-hosted file conversion application that can run locally using Docker.

This guide focuses primarily on document formats such as:

- DOCX
- XLSX
- PPTX
- PDF

## Why Run It Locally?

Running ConvertX locally can help reduce the need to upload private documents to third-party file-conversion websites.

The basic setup is:

```text
Your File
   ↓
Browser
   ↓
localhost:3000
   ↓
ConvertX
   ↓
Docker Desktop
   ↓
Your Computer
```

## Requirements

- Windows 10 or Windows 11
- Docker Desktop
- PowerShell
- A modern web browser
- Sufficient disk space for Docker and ConvertX
